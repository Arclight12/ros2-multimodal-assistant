# Repository Structure

This document describes the layout of the repository and the purpose of each
top-level entry.

```

│   ├── assistant_msgs/                 # Shared ROS 2 interfaces

│   │   ├── msg/ObjectSelection.msg     # Selection message
│   │   ├── srv/ScanWorkspace.srv       # Scan service

│   ├── assistant_perception/           # Workspace understanding

│   │   ├── assistant_interaction/
│   │   │   ├── __init__.py
│   │   │   ├── voice_node.py
│   │   │   ├── gaze_node.py
```

Notes:

- RViz is intentionally **not** shipped: there is no robot model, TF tree, or
  MoveIt integration yet, so an RViz config would be misleading dead weight.
- The example object map (`config/object_map_example.json`) is sample data. A
  scan writes to the **runtime** map at `~/.ros/ros2_multimodal_assistant/`,
  never into the repository.

## What Belongs Where

| Directory | Purpose                                                      |
|-----------|--------------------------------------------------------------|
| `src/`    | All ROS 2 packages (colcon workspace root).                  |
| `docs/`   | Developer-facing technical documentation.                    |
| `models/` | Downloaded model weights; never committed.                   |
| `scripts/`| Convenience helpers (mirror scripts, env setup, etc.).       |
| `.github/`| CI workflows.                                                |
| `requirements.txt` | pip dependencies for the AI/vision stack.            |

## Build Artifacts (Never Committed)

`build/`, `install/`, `log/` directories and `*.egg-info/` are generated by
colcon/pip and excluded via `.gitignore`.
